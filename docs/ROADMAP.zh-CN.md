# 路线图

**语言：** [English](ROADMAP.md) | 中文

本路线图描述 `emby-intro-marker-sidecar` 公开仓库的当前状态，并区分已经可用的内容和每个使用者需要在自己环境里补完的内容。

## 已经足够使用

- dry-run 检测
- 报告复核流程
- 可选的显式写回路径

## 需要本地补全

- 根据你的媒体库调整检测阈值
- 确认 SQLite 表结构/模板与你的 Emby 版本兼容
- 增加针对一次性测试数据库的集成测试

## 建议改进

- 增加基于 fixture 的检测测试
- 改进报告解释和置信度展示
- 写回前增加安全迁移检查
- 补充不同 Emby 目录布局的部署示例

## 仍值得补充的文档

- 使用非私有演示数据制作截图或短录屏。
- 为常见请求/响应补完整 API 示例页。
- 为持久化数据路径补备份和恢复说明。
- 等公开用户开始部署后，基于真实问题整理排障页。
